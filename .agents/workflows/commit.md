---
description: Commit
---

Follow these steps when asked to commit code changes.

1. **Check Status**: Look at the changed files to understand what work was done.
2. **Plan Commits**: Decide if changes should be one big commit or split into multiple smaller commits. Group related changes together.
3. **Commit Code**: For each group of changes:
   - Stage the specific files.
   - Write a clear commit message. The message must have a short title and a brief description of what changed.
   - Run the commit command.
4. **Ask to Push**: Tell the user what commits you just made. **Always ask the user for permission before pushing.**
5. **Push Code**: Only run `git push` after the user says yes.
